# Family Locator — прототип карты и зон

Интерактивный веб-прототип для ТЗ Family Locator (см. [PRD.md](./PRD.md)): карта, геозоны (создание/удаление, по клику или по текущей геопозиции), симуляция входа/выхода из зон, автоотключение трекинга в 15 лет, режим «совместное присутствие», экран согласия и индикатор трекинга для ребёнка.

Чистый HTML/CSS/JS + [Leaflet](https://leafletjs.com), без сборки и без бэкенда — данные хранятся в `localStorage` браузера.

## Запуск

Открыть `start.bat` (поднимает локальный сервер на PowerShell и открывает `http://localhost:5174/`), либо открыть `index.html` напрямую в браузере.
